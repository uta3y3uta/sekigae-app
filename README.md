# 🎲 席替えアプリ ワクワク版

小学校の席替えを、子どもたちがワクワクするUIで楽しく行うための単一HTMLアプリ。

## ✨ 特徴

- **データ取込**: 1人ずつ／コピー&ペースト／Excel・CSV からの一括読み込み
- **上下／左右 2分割の手動配置**: 「現在の座席」と「新しい座席」を同時に表示し、机をドラッグ&ドロップで自由に配置
- **3 種のシャッフル**:
  - **🎰 全シャッフル** — ガラポン抽選機の派手な演出付きランダム配置
  - **↔️ 班外シャッフル** — 4人班の班番号を活用した構成的シャッフル（1番→+1班、2番→+2班、3番→-1班、4番→-2班）
  - **🔄 班内シャッフル** — 班内で時計回り／反時計回りにローテーション
- **席替えメーカー風の設定モーダル** — 男女分離、離席ルール、固定席、班外オフセット規則、演出速度などをまとめて調整
- **永続化**: LocalStorage で名簿・座席・履歴を自動保存
- **エクスポート／インポート**: JSON で全データを書き出し／取り込み

## 🚀 使い方

`席替えアプリ_新.html` をブラウザで開くだけ。サーバー不要・インストール不要。

1. **名簿** タブで生徒情報を登録
2. **席替え** タブでシャッフルボタンを押す or 机をドラッグ&ドロップで配置
3. 「✨ この席に決定！」で確定 → 履歴に保存
